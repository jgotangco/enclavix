### Ticket files, routing and privacy controls

Ticket attachments use a separate document purpose and are available to the current requester and authorized association administrators. Other occupants of the same property cannot download them. Pending or rejected scans withhold the file. Administrators can route a ticket to an active association administrator, record a future response deadline and cite a clean attachment as closure evidence. Existing callers may resolve with a reason alone.

Privacy controls record an explicit document retention period and association-wide hold state with audit. No retention duration is seeded. Privacy request fulfillment and any record disposition remain pending D08 policy. The existing expiring tenant registry export now includes S05 announcements, tickets, privacy request records, settings and versioned file metadata. It does not include file bytes or a full financial archive.
