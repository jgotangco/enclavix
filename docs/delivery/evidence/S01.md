- Add tenant/community/hierarchy/property/asset, scoped people/memberships/roles/designations, temporal property and asset relationships, import staging, operation/outbox/audit primitives and private document metadata.

- Record architecture decisions and service, compatibility, worker and storage contracts, with D01–D04 recommendations and unresolved owners.
