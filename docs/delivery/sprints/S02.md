## Deliverables
Implement verified auth, invitations/application approval, MFA for privileged users, trusted membership resolution, recovery and real sign-out/revocation. Remove production demo-persona authority. Implement deny-by-default RLS and storage policies plus trusted service checks; roles and civic titles separate. Add session and support-access policy. Model user approval/elevation operations so users cannot grant themselves roles. Provide local auth fixtures and a complete isolation test matrix.

## Acceptance evidence
Anonymous/forged-cookie access denied. A resident cannot request another unit or tenant record or object. Modified API and Android-style requests cannot select a privileged role or trusted tenant. Revoked sessions/memberships cease to authorize access according to the documented revocation bound. MFA, recovery and logout exercise real provider flows. Tests cover API, direct database, storage and support-access boundaries.

## Exclusions
No production resident import, finance engine or broad impersonation shortcuts.
